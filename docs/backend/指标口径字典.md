# 指标口径字典

**用途**：产品流水线与论文实验**共用**的指标定义事实来源。产品侧实现（Python worker）与论文侧实验代码都必须逐字对齐本字典，杜绝"指标断层"（`../../PROJECT_REQUIREMENTS.md` 4.3）。
**创建**：2026-09-28（此前指标只有名字没有定义，产品与论文口径无法核对）

---

## 1. 总则

| # | 规则 |
|---|---|
| 1 | 每个指标定义 = **输入 + 计算公式 + 参数 + 单位 + 有效条件**，五者缺一不可 |
| 2 | 计算实现随 worker 发布，版本号写入 `AnalysisJob.dspLibVersion`；论文实验代码同样带版本 |
| 3 | **参数一旦冻结不得单方面改动**：改公式或参数 = 换口径，旧数据不可比，必须升 `dspLibVersion` 并在论文中说明 |
| 4 | 标注 ⚠️ 的参数为**待论文实验对齐**项：先按本字典默认值实现，论文实验定稿后回填冻结 |
| 5 | 文本指标基于 ASR 文本时，`computedFrom = ASR`；基于人工转录时 `= MANUAL`；**两者永不混算** |

## 2. 四个产品指标

### 2.1 `SPEECH_RATE` 语速

| 项 | 定义 |
|---|---|
| 输入 | 有效语音段（去除静音段后）时长 + 转写字符数 |
| 公式 | `有效语音时长(秒) 内的字符数 / 有效语音时长` |
| 字符口径 | 中文按字计数（含标点**否**：**不含标点**）；英文按词计数 |
| 单位 | 字/秒 |
| 有效条件 | 有效语音时长 ≥ ⚠️30 秒，否则该指标置 `null`（样本太短不稳） |
| ⚠️ 待对齐 | 最短有效时长阈值（默认 30 秒）；字符是否含语气词（默认含） |

### 2.2 `PAUSE` 说话流畅度（停顿）

| 项 | 定义 |
|---|---|
| 输入 | VAD（webrtcvad）输出的语音段/静音段序列 |
| 公式 | `总静音时长 / 总时长`（`pauseRatio`）；另有 `longPauseCount` = 长停顿次数 |
| 长停顿定义 | 连续静音 ≥ ⚠️1000 毫秒 计一次 |
| 单位 | pauseRatio ∈ [0,1]；longPauseCount 为次数 |
| 有效条件 | 总时长 ≥ ⚠️30 秒 |
| ⚠️ 待对齐 | 长停顿阈值（默认 1000ms）；VAD 灵敏度参数（ aggressiveness = 2，默认） |

### 2.3 `VOCAB` 用词丰富程度

| 项 | 定义 |
|---|---|
| 输入 | 分词后的转写文本（ASR 或人工转录） |
| 公式 | **MATTR**（移动平均类符形符比）：窗口 ⚠️10 个词，逐步滑动，取各窗口 TTR 的均值 |
| 为什么不用 TTR | 短样本 TTR 随文本长度剧烈波动（分析流水线 4 节既有结论） |
| 分词 | 中文用 jiecaiac（jieba，⚠️词典版本冻结在 `dspLibVersion`）；英文按空格 |
| 单位 | [0,1] |
| 有效条件 | 分词后词数 ≥ ⚠️50；ASR 整体置信度 < ⚠️0.6 时文本指标整体置 `null` |
| ⚠️ 待对齐 | MATTR 窗口大小（默认 10）；最小词数（默认 50）；置信度下限（默认 0.6） |

### 2.4 `COHERENCE` 说话连贯性

| 项 | 定义 |
|---|---|
| 输入 | 分词后的转写文本 |
| 公式 | 三个子指标的**等权均值**：`connectiveRate`（连接词数/句子数）、`contentFunctionRatio`（实词/虚词比，⚠️词表冻结）、`propositionDensity`（⚠️信息单元数/句，抽取规则待论文对齐） |
| 句子定义 | 按转写分段标点切分；ASR 无标点时按分段（segment）切 |
| 单位 | [0,1]（归一化后） |
| 有效条件 | 句子数 ≥ ⚠️5；同 2.3 的置信度下限 |
| ⚠️ 待对齐 | 连接词表、虚词表、信息单元抽取规则（论文实验定稿后冻结为附录文件） |

## 3. 质量门控输入（QualityGate）

质量门控的**阈值与分级规则以 `../../PROJECT_REQUIREMENTS.md` 5.3 为唯一事实来源**，本字典只定义输入量的计算方式：

| 输入量 | 计算方式 | 来源 |
|---|---|---|
| `snrDb` | 语音段能量 / 静音段能量，对数（librosa 计算），⚠️静音段取样策略待对齐 | worker 声学计算 |
| `silenceRatio` | 同 2.2 pauseRatio 口径（整条音频，不去除首尾） | worker 声学计算 |
| `durationSec` | 音频有效时长 | 上传元数据 + worker 复核（以 worker 为准） |
| `asrConfidence` | ASR 引擎返回的整体置信度，跨引擎不可比时以 `asrEngine` 字段区分口径 | ASR 结果 |

**记录级有效条件**：`qualityFlag = VALID` 才参与基线与趋势（基线与状态机 3 节）；`SUSPECT` 保留展示不参与趋势；`INVALID` 保留记录不参与一切计算。

## 4. 降级时的口径

| 场景 | 处理 |
|---|---|
| ASR 失败（computedFrom 无法产生） | 四指标中 `SPEECH_RATE`、`PAUSE` 仍可算（不依赖转写）——**注意**：`SPEECH_RATE` 的字符数需要转写，ASR 失败时若走"字符/秒"口径则一并置 `null`；此时可降级输出"音节估计语速"⚠️（是否引入待论文定，默认不引入，宁缺毋假） |
| 文本指标部分置 `null` | 趋势按"指标×时间点"稀疏处理，缺失点不插值 |
| `computedFrom` 混合 | 同一 subject 的基线**按 `computedFrom` 分组计算**（论文口径 vs 产品口径不混算），接口按组分别报告 `isEstablished` |

## 5. 冻结流程

1. 论文实验侧跑通四指标 → 双方代码对同一批样本出数 → 数值 diff 为 0
2. 本字典 ⚠️ 项回填定稿，移除 ⚠️ 标记，记录冻结日期与 `dspLibVersion`
3. 之后任何改动 = 新口径版本，旧数据不回算，论文中说明版本分界
