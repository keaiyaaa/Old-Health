## 1. 原型设计目标与边界

### 1.1 目标
1. 让**子女**在 10 秒内回答"这周正常吗"（P1 张慧敏，通勤路上刷一眼）
2. 让**老人**在 3 秒内知道该干嘛，且全程不产生"被检查"的感觉（P2 王秀兰）
3. 让**医生**拿到的是 1–2 页结构化材料，不是一堆手机截图（P4 李医生）

### 1.2 设计边界（不可逾越）
| 约束 | 说明 |
|---|---|
| 老人端零指标 | 老人端不出现任何数字、趋势、状态色、百分比 |
| 无红色 | 整个产品不使用红色系。最高级别只到深橙 |
| 无绝对判断 | 所有指标只与"用户自己的基线"比较，不出现跨用户对比、不出现绝对分数 |
| 必带退路 | 任何"有变化"的提示旁必须并列非疾病解释，视觉比重 ≥1/3 |
| 不显示原始数值 | 趋势只给方向与状态标签，不给数字 |
| 禁用词 | 诊断、确诊、患病、概率、筛查、异常、恶化、痴呆、评分、MMSE、MoCA（后两者仅研究模式） |

### 1.3 原型覆盖范围
共 **15 个页面**：老人端 4、引导 2、家属端 8、通用 1。

## 2. 信息架构

### 2.1 老人端（4 屏，零指标零趋势）

```
P-E1 录音页（默认首页）
  ├─ P-E2 完成页        （录音结束后自动进入，3 秒后返回）
  ├─ P-E3 日历页        （右上角入口；只看"哪天录过"，可回放）
  └─ P-E4 设置          （字号 / 语音提示 / 家人绑定 / 模式切换 / 退出）
```

**关键决策：老人端没有"趋势"这个入口。** 不是折叠，是根本不存在。

### 2.2 家属端（8 屏）

```
P-F1 总览
  ├─ P-F2 趋势详情        （4 指标 Tab）
  ├─ P-F3 记录列表 → P-F4 记录详情
  ├─ P-F5 话题库与提醒
  ├─ P-F6 就医准备
  ├─ P-F7 数据与隐私
  └─ P-F8 研究模式        （仅研究版可见）
```

### 2.3 引导与通用

```
P-O1 产品说明与免责  →  P-O2 知情同意（含敏感个人信息单独同意）  →  绑定老人设备
P-C1 模式选择 / 登录（启动页）
```

## 4. 设计规范

### 4.1 色彩 Token（白 + 绿体系）

整体基调：**纯白卡片 + 绿色主色 + 极浅绿白页面底**。绿色同时承担"品牌色"和"稳定状态"两个角色，这样整个产品第一眼是安静、干净的。

| Token | 值 | 用途 |
|---|---|---|
| `bg/page` | `#F5F8F5` | 页面底色（极浅绿白，不是纯白，让白卡片能浮起来） |
| `bg/card` | `#FFFFFF` | 卡片、输入框、弹层 |
| `bg/subtle` | `#EAF4EE` | 次级区块、指标卡底、选中态底 |
| `brand/primary` | `#17845A` | **主绿**：主按钮、录音按钮、趋势折线、当前点 |
| `brand/deep` | `#0B5138` | 深绿：页面大标题、按钮按下态、S6 已处理 |
| `brand/light` | `#D9EDE3` | 浅绿：标签底、Tab 选中底、勾选态 |
| `text/primary` | `#1A2B22` | 正文、标题（近黑带一点绿，比纯黑柔和） |
| `text/secondary` | `#5F7A6D` | 说明、时间 |
| `text/tertiary` | `#93A79C` | 提示、占位、禁用 |
| `border/line` | `#DCE7E0` | 分隔线、卡片描边 |
| `status/stable` | `#17845A` | S2 稳定（= 主绿） |
| `status/watch` | `#D98E1F` | S4 有变化 |
| `status/referral` | `#B4531A` | S5 建议评估（**最深只到这里**） |
| `status/neutral` | `#93A79C` | S0 / S1 / S3 数据不足、基线建立中 |
| `status/resolved` | `#0B5138` | S6 已处理 |
| `chart/line` | `#17845A` | 趋势折线（与主绿一致） |
| `chart/band` | `#17845A` @ 12% | 基线带 |

**两条必须保留的例外（这不是配色不统一，是功能刚需）：**

1. **`status/watch` 与 `status/referral` 必须保留暖色。** 如果整站只有绿色，"有变化"和"稳定"在视觉上无法区分——而这两者的差别正是整个产品的核心信息。处理方式：**暖色只出现在 4px 竖条、状态标签文字、数据充分度条三处，面积极小**，整体观感仍然是白 + 绿。
2. **红色依然不在 Token 表里。** 这是刻意的，不是遗漏。任何想加红色的需求都要先回到本文档 1.2 节。

### 4.2 字体与字号

| 场景 | 老人端 | 家属端 |
|---|---|---|
| 页面主标题 | 26sp / Medium | 20sp / Medium |
| 话题卡正文 | 24sp / Medium | — |
| 正文 | 20sp / Regular | 15sp / Regular |
| 次要说明 | 18sp / Regular | 13sp / Regular |
| 极小标注 | 16sp | 12sp |

老人端提供三档字号（标准 / 大 / 特大），**默认"大"**。家属端字号跟随系统。

### 4.3 间距与圆角
- 间距序列：4 / 8 / 12 / 16 / 24 / 32
- 页面左右安全边距：老人端 20，家属端 16
- 卡片圆角 12，按钮圆角 12，大录音按钮为圆形
- 卡片内边距 16（家属端）/ 20（老人端）

### 4.4 组件库（8 个基础组件）

| 组件 | 说明 |
|---|---|
| **大录音按钮** | 直径 140（老人端）。未录：主色实心圆 + "开始说话"；录音中：外环进度 + 秒数 + 简易波形 |
| **话题卡** | 老人端 24sp 大字，白底卡片，一行一句 |
| **状态横幅** | 家属端首页顶部。左侧 4px 状态色竖条 + 标题 + 说明 + 可选行动按钮 |
| **指标卡** | 2×2 网格。指标名 + 迷你折线（60×18）+ 状态标签 |
| **趋势图** | 折线 + 基线带（阴影区）+ 均值虚线 + 当前点。可叠加事件标注竖线 |
| **数据充分度条** | 常驻，不可关闭。有效记录 <4 条时强制显示 |
| **事件标注 Chip** | 可增删的小标签：感冒 / 失眠 / 情绪低落 / 住院 / 旅行 / 家庭事件 |
| **免责声明条** | 底部常驻一行小字 + 点击展开完整说明 |

### 4.5 适老化硬指标（老人端）
- 正文 ≥18sp，按钮文字 ≥20sp，录音按钮 ≥140dp
- 对比度 ≥4.5:1
- 点击区 ≥48×48dp，主操作位于屏幕下半区
- 全流程单手可操作，**无二级菜单、无滑动切换**
- 关键操作可语音朗读（TTS）
- **失败态不使用红色、不出现"错误/失败"字样**

|---|---|
| 元素 | 问候 20sp、话题卡 24sp、录音按钮 140dp、提示 18sp、上次记录 16sp |
| 状态 | 未录 / 录音中 / 待上传 / 已完成 |

```
┌────────────────────────────────┐
│                                │
│           ✓  120dp             │  ← 主色对勾，非绿色也非红色
│                                │
│      今天记好了，谢谢您。        │  ← 26sp，随机文案
│                                │
│   ┌────────┐   ┌────────┐      │
```

## 6. 关键交互说明

### 6.1 录音流程（老人端）
```
点按开始 ──▶ 秒数跳动 + 波形 ──▶ 点"说完了" ──▶ 本地落盘 ──▶ 显示正向反馈
     │                                    │
     └─ 无倒计时压力                        └─ 断网也照常，只是延迟上传
```
- 不设自动结束倒计时；超过 5 分钟才自动结束
- 录音 <10 秒 → 静默丢弃，不提示失败
- 完成后 3 秒自动回首页，老人不需要点"返回"

### 6.2 状态横幅的升级与降级
```
S0 未开始 ──▶ S1 基线建立中 ──▶ S2 稳定 ⇄ S3 波动
                                  │
                    连续 3 次偏离 ──▶ S4 有变化（橙）
                                  │
                  持续 4 周且多项 ──▶ S5 建议评估（深橙）
                                  │
                      家属标记已就诊 ──▶ S6 已处理
                                  │
                    连续 2 周回到基线 ──▶ 自动降回 S2
```
**规则**：升级缓慢、降级自动、不用红色、必带非疾病解释。

### 6.3 同步状态的三种表现
| 情况 | 表现 |
|---|---|
| 正常 | "最近同步：2 分钟前"（灰） |
| 超过 24 小时 | "最近同步：3 天前，数据可能滞后"（橙） |
| 有失败记录 | "有 2 条还没传上去，正在重试"（灰，不吓人） |
