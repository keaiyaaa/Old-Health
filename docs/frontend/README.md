### 3.1 共享层（跨模块复用）

**提升为共享代码的门槛：两个以上模块稳定复用。** 不满足就留在模块内。

| 共享物 | 内容 | 归属 |
|---|---|---|
| 设计令牌 | 颜色、字号、间距、圆角 | `ui/theme/` |
| 基础组件 | 8 个基础组件（见 `原型设计说明书.md` 4.4） | `ui/components/` |
| 状态横幅 | S0–S6 渲染组件 | `ui/components/StatusBanner` |
| 文案中心 | 全部用户可见文案的 key → 文案映射 | `ui/copy/` |
| 权限判定 | 角色 → 可见性/可操作性判定 | `domain/permission/` |
| 错误映射 | 错误码 → 用户可理解文案 | `domain/error/` |
| 埋点 | 统一埋点入口 | `infra/analytics/` |

**硬规则**

- 页面组件**不得**直接拼请求（走 Repository）
- 页面组件**不得**直接写权限字符串（走 `domain/permission/`）
- 页面组件**不得**直接写用户可见文案（走 `ui/copy/`，便于统一做禁用词校验）

4. 越权路由不注册，不是靠运行时拦截

## 5. 跨模块通用约定

### 5.1 页面状态五态

每个页面**必须**实现这五种状态，缺一不可。逐页矩阵见 `原型设计说明书.md` 附录 B。

| 状态 | 要求 |
|---|---|
| 正常 | 有数据时的完整呈现 |
| 空 | 明确说明"为什么空"和"下一步做什么"，不留白 |
| 加载 | 骨架屏或进度指示；**老人端不用转圈动画** |
| 错误 | 用户可理解的文案 + 可执行的下一步；**不显示错误码** |
| 无权限 | 说明原因 + 如何获得权限 |

外加一态：**数据不足**（指标类页面专有，见 `../PROJECT_REQUIREMENTS.md` 5.3）。

### 5.2 异常状态硬约束

| 场景 | 约束 |
|---|---|
| 老人端任何失败 | **不出现错误提示**，只用温和文案（如"等一下再试试"） |
| 断网 | 录音功能**完全正常**，不降级；上传静默排队 |
| 老人多日未同步 | 家属端必须主动提示"数据可能滞后"，不能让用户以为老人没录 |
| 文本指标为 `null` | 该指标 Tab 显示"本周文本分析未完成"，不显示 0 或空折线 |
| ASR 失败 | 保留声学指标，文本指标置空，不整条作废 |

### 5.3 无障碍与适老（老人端为硬指标）

- 正文 ≥18sp，按钮文字 ≥20sp；三档字号
- 对比度 ≥4.5:1；点击区 ≥48dp（录音按钮 ≥120dp）
- 全流程单手可操作，主操作位于屏幕下半区
- 关键操作配 TTS；支持系统"减少动态效果"
- 遵循 WCAG 2.2 AA 核心要求

### 5.4 响应式

- 适配 360dp–600dp 宽；折叠屏展开态不改变老人端布局（只增大留白）
- 老人端**不横屏**（锁定竖屏），家属端允许横屏看趋势图
- 平板/大屏：家属端趋势图可加宽，老人端保持单列

### 5.5 禁用词与文案校验

- 全部用户可见文案集中在 `ui/copy/`，便于构建期做禁用词扫描
- 禁用词表见 `../PROJECT_REQUIREMENTS.md` 5.4
- **CI 中必须有一个步骤**：全量扫描文案资源，命中禁用词即构建失败

## 6. 模块文档的固定结构

每个 `modules/*.md` 必须包含以下小节，缺一不可：

1. 模块职责与边界（含"不做什么"）
2. 覆盖的页面与路由
3. 角色与权限
4. 组件边界（哪些是页面级、哪些提升为共享）
5. 状态管理（状态来源、缓存策略、单一数据源）
6. 接口依赖（指向 `../api/` 的具体文件与接口名）
7. 异常状态与降级
8. 响应式与可访问性
9. 测试要求
10. 验收标准（可逐项勾选）
