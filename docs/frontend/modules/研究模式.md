# 模块：研究模式

**覆盖需求**：FR-8（研究模式）
**覆盖页面**：P-F8 研究模式
**路由**：`family/research`
**默认状态**：**关闭，普通用户不可见**

---

## 1. 模块职责与边界

### 1.1 职责

为论文提供**可标注、可复现、可导出**的语音数据集采集通道，并支持与临床量表的效度验证。

**这是唯一直接服务论文目标的模块**（见 `../../PROJECT_REQUIREMENTS.md` 4.11）。它不对应任何用户需求（UR），这一点是刻意的，需求评审时要能解释清楚。

### 1.2 明确不做

| 不做 | 理由 |
|---|---|
| 不做自动量表评分 | 量表由人评估，App 只录入 |
| 不做模型推理（不在客户端跑 AD 分类） | 模型在论文侧离线跑 |
| 不做实时反馈给受试者 | 会污染后续采集 |
| 不做多中心权限管理（一期） | 单研究者场景，不预建 |
| 不做数据标注工具（一期） | 标注在电脑侧做，App 只导出 |

## 2. 页面与路由

| 页面 | 路由 | 可见条件 |
|---|---|---|
| P-F8 研究模式 | `family/research` | 研究模式开关开启 + 当前账号为 `RESEARCHER` |

**入口可见性**：开关在 P-F7 数据与隐私页，**默认关闭**。开启后需签署研究知情同意（FR-8.1）。

**隐藏机制**：路由在导航图中**条件注册**。开关关闭时路由不存在，不是靠界面隐藏。

## 3. 角色与权限

| 操作 | `RESEARCHER` | `CG_EDITOR` | `ELDER` |
|---|---|---|---|
| 查看研究模式 | ✅ | ❌ | ❌ |
| 录入临床量表 | ✅ | ❌ | ❌ |
| 查看受试者真实姓名 | ❌（**只显示匿名 ID**） | — | — |
| 导出原始数据集 | ✅ | ❌ | ❌ |
| 查看依从性报表 | ✅ | ❌ | ❌ |
| 导入人工转录 | ✅ | ❌ | ❌ |
| 撤回研究同意 | ✅（作为研究方操作） | ❌ | ✅（作为受试方） |

**匿名化规则**：研究模式界面与导出文件中**不出现真实姓名、手机号、精确生日**。受试者以 `SUBJ-0001` 形式呈现。映射关系只存在于服务端，且单独授权访问。

## 4. 组件边界

| 组件 | 级别 | 说明 |
|---|---|---|
| `ResearchScreen` | 页面级 | 主页面 |
| `ScaleInputForm` | 页面级 | 量表录入 |

| `AdherenceReport` | 页面级 | 依从性报表 |

| `TranscriptImport` | 页面级 | 人工转录导入 |

### 4.1 结构化任务引导的一致性要求

任务引导语**必须逐字固定**，跨被试完全一致（FR-8.4）。实现上：

- 指导语从 `ui/copy/research_task_guide.json` 读取，**不硬编码在组件里**
- 该文件受版本控制，改动需在 `../../planning/` 记录，因为它影响数据可比性
- 计时器不可由用户调整
- 任务顺序不可跳过、不可打乱

## 5. 状态管理

```
ResearchViewModel
├── enabled：研究模式开关（本地 + 云端）
├── consent：研究知情同意状态
├── subjects：匿名受试者列表
├── scales：量表记录（按受试者 + 日期）
├── taskProtocol：当前周次应完成的任务
└── exportConfig：导出内容勾选
```

**研究数据与产品数据在同一存储中，通过字段区分**（`clinical` 字段仅在研究模式写入）。不建独立数据库——一期规模不需要，且会增加同步复杂度。

## 6. 接口依赖

| 用途 | 接口 | 文件 |
|---|---|---|
| 研究知情同意 | `POST /v1/research/consent` | `../../api/API-06-研究模式.md` |
| 量表录入 | `POST /v1/research/clinical` | 同上 |
| 受试者列表（匿名） | `GET /v1/research/subjects` | 同上 |
| 依从性报表 | `GET /v1/research/adherence` | 同上 |
| 数据集导出 | `GET /v1/research/export?subjectId=&scope=` | 同上 |
| 人工转录导入 | `POST /v1/research/transcript` | 同上 |

**导出内容**（FR-8.6）：音频文件 + ASR 文本 + 人工校订文本 + 指标 CSV + 量表 CSV，打包为 zip，字段与论文数据字典一致。

## 7. 异常状态与降级

| 异常 | 表现 | 降级 |
|---|---|---|
| 未签研究同意 | 研究模式不可进入，引导签署 | — |
| 同意已撤回 | 立即不可访问研究数据；已导出数据按伦理承诺处理 | 明确告知不可追溯部分 |
| 导出体积过大 | 提示分批导出（按受试者或时间范围） | — |
| 音频部分缺失 | 导出清单中标注缺失条数 | 不静默跳过 |
| 量表未录入 | 依从性报表中标记为缺失 | — |
| 网络失败 | 导出任务可重试 | 已生成的本地文件不重复下载 |

## 8. 响应式与可访问性

| 项 | 要求 |
|---|---|
| 宽度 | 360dp–600dp；横屏允许 |
| 表格 | 依从性报表在窄屏用卡片列表替代表格 |
| 字号 | 跟随系统 |
| TalkBack | 表单控件完整可读 |
| 对比度 | ≥4.5:1 |

研究模式面向研究者，**不适用适老化要求**（那是老人端的硬指标）。但对比度与点击区仍按通用标准。

## 9. 测试要求

| 类型 | 覆盖 |
|---|---|
| 单元 | 匿名 ID 生成、导出字段完整性、任务协议按周次推进 |
| **隔离测试** | 研究模式关闭时，断言路由不存在、数据不可访问 |
| **匿名化测试** | 全量导出文件中扫描真实姓名 / 手机号，命中数为 0 |
| 一致性测试 | 任务指导语跨版本不变（对比基准文件） |
| 集成 | 量表录入 → 依从性报表 → 导出 全链路 |
| 边界 | 0 受试者 / 单受试者 1000 条 / 全部缺量表 |

## 10. 验收标准

- [ ] 研究模式**默认关闭**，C 端用户不可见（FR-8.1）
- [ ] 关闭时路由不存在（条件注册），不是界面隐藏
- [ ] 研究知情同意与产品同意书**分离**，可单独撤回（FR-8.1）
- [ ] 界面与导出文件中**不出现真实姓名**，只有匿名 ID（FR-8.2）
- [ ] 量表录入记录分数、日期、评估人（FR-8.3）
- [ ] 结构化任务指导语逐字固定，跨被试一致（FR-8.4）
- [ ] 依从性报表含完成率、缺失分布、**代录占比**（FR-8.5）
- [ ] 导出字段与论文数据字典一致（FR-8.6）
- [ ] 支持人工转录导入，与 ASR 文本并存（FR-8.7）
- [ ] 撤回研究同意后，研究数据立即不可访问
- [ ] 研究模式**不影响 C 端任何页面的呈现**（隔离验证）

> ⚠️ 若论文使用自采数据，必须有伦理批件（IRB）。见 `../../planning/待确认事项.md` C4。
