## 7. 发现与错误记录

1. **遗留代码隐性炸弹**：`Routes.kt` 的 KDoc 注释里写了 `` `elder/*` `` 与 `` `family/*` ``。Kotlin 块注释支持嵌套，这两个 `/*` 被当成嵌套注释开符号，整个文件被吞进未闭合注释（编译报 "Unclosed comment"）。已改为不含 `/*` 的表述，并全库排查确认无同类问题。
2. **AppState 平台声明冲突**：delegated property 自动生成 `setXxx` 的 JVM 签名，与同名公开函数 `setXxx` 冲突（`Platform declaration clash`）。该文件属于越界产物，从未编译过所以此前未暴露。已将函数改名 `applyXxx` 并同步调用点。
3. `produceState(initialValue = null)` 不写泛型时被推断为 `Nothing?`，后续 `.id` 报 Unresolved。已显式标注 `produceState<Subject?>`。
4. 编译期其余报错均为新写代码的 import 错误（`LifecycleEventObserver` 包名），已修复。
5. 构建告警仅 `libandroidx.graphics.path.so` 未裁剪（debug 构建正常现象，与工程方案 §2.3 记录一致）。
