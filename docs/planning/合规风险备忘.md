# 合规风险备忘：医疗器械边界与敏感个人信息

**日期**：2026-09-27
**性质**：⚠️ **产品侧风险识别，不构成法律意见。** 具体结论需法务或医疗器械注册顾问出具书面意见。

> 本文档是 `../PROJECT_REQUIREMENTS.md` 第 9 章的展开。它回答一个问题：**这个产品的医疗建议有风险吗？**

---

## 1. 核心结论

**风险不在"要不要给建议"，而在建议的"权威感"与"数据流向"。**

一句「建议就医评估」本身是安全的——它是**分诊提示**，不是诊断，所有血压/血糖记录类 App 都这么写。真正决定风险高低的是：

1. 这句话的**权威感有多强**（是否附带概率、分数、临床术语）
2. 它最终**流向谁**（用户自己看，还是包装成报告递给医生）

**同一句「建议就医」，推给用户是健康提示，做成结构化报告递给医生就变成决策支持软件。**

---

## 2. 四层风险

| 层 | 风险 | 严重度 | 核心判断 |
|---|---|---|---|
| L1 | **监管定性** | 高 | 产品是否被认定为医疗器械 |
| L2 | **广告与渠道** | 中高 | 宣传语出现"筛查/早筛/检测"即触发《广告法》第 17 条；应用商店医疗类目要资质 |
| L3 | **个人信息** | 高 | 语音含声纹 = 生物识别 + 医疗健康，**双重敏感个人信息** |
| L4 | **真实伤害** | **最高** | 假阴性延误就诊 / 假阳性制造焦虑 |

**L4 最容易被忽略，但它是最不可辩解的风险。** 监管处罚是概率性的，而误导是必然发生的。

---

## 3. L1 监管定性：已核实的判据

### 3.1 最有利的一点

《人工智能医用软件产品分类界定指导原则》（2021 年第 47 号通告）对 AI 医用软件的定义是：

> 基于**医疗器械数据**，采用人工智能技术实现其**医疗用途**的独立软件。

**两个条件缺一不可。而语音不是医疗器械数据。**

2025 年《康复类数字疗法软件产品分类界定指导原则》的官方解读中说得更直接：

> 部分大模型产品可基于用户输入的个人指标、参数等，生成运动康复训练计划等，属于对主诉信息处理的软件产品，**不涉及医疗器械数据**，根据《人工智能医用软件产品分类界定指导原则》，**应不作为医疗器械管理**。

**这是我们主张"非医疗器械"的第一道防线。**

### 3.2 最不利的一点

同一份指导原则明确：

> 用于给出**诊断结论**或药物计算等的医用软件，按照第三类医疗器械管理。

以及《医疗器械分类目录》21-04 决策支持软件：

> 计算机软件对病变进行自动识别，对病变的性质等给出**临床诊断治疗依据和/或建议**的决策支持软件 → 第三类

### 3.3 分类界定的历史数据（一事一议，无定论）

| 年份 | 产品 | 结果 |
|---|---|---|
| 2022 | 认知功能评估与训练软件 | **三类** |
| 2023 | 认知功能障碍评估与治疗软件 | **三类**（但产品描述基于**头颅磁共振影像**，与我们不同） |
| 2020 | 认知功能障碍治疗软件 | 二类 |
| 2020 | 大脑生理与认知功能辅助评估系统 | 二类 |
| 2022 | 帕金森辅助评估软件 | **二类**（最接近我们的类比物） |
| 2020–21 | 中医舌诊体质健康状态筛查软件 | 二类 |

**重要澄清**：61 款 21-04 决策支持软件中，仅 5 款被划为二类。但分类界定汇总**不是法规文件、无强制效力**——业内的共识是"金标准"是《医疗器械分类目录》+ 分类界定指导原则，汇总只作参考。

**所以不能简单推出"认知类评估软件 = 三类"。** 2023 年那个案例的数据源是医学影像（真正的医疗器械数据），与我们的语音不同。

### 3.4 可以主张"非医疗器械"的理由

| 理由 | 依据 |
|---|---|
| 处理对象是语音，**不是医疗器械数据** | AI 指导原则的排除条件 |
| 核心功能是个人健康记录与趋势呈现，**不提供疾病干预措施** | 康复类指导原则对"数字疗法"的界定 |
| 输出**不构成诊断结论** | 不输出概率、评分、风险等级 |
| 定位是**个人日常健康管理** | 康复类指导原则明确"健康管理类产品不具备医疗用途，不按照医疗器械管理" |

### 3.5 会破坏上述论证的三个动作（必须守住）

| # | 禁止动作 | 后果 |
|---|---|---|
| 1 | 输出概率、评分、风险等级、置信度 | 构成评估输出 |
| 2 | 生成面向医生的结构化临床建议 | 落入 21-04 决策支持软件 → 三类 |
| 3 | 宣传"早筛 / 筛查 / 检测" | 构成功能声称 |

### 3.6 唯一能拿到确定答案的路径

走一次**正式分类界定申请**（《国家药监局关于规范医疗器械产品分类界定工作的公告》2024 年第 59 号，2024-09-01 施行）：

- 新研制产品 → 报器械标管中心
- 管理类别存疑的境内产品 → 报**省级药品监督管理部门**
- **前置条件**：已完成前期研究、产品基本定型

**当前尚不具备条件**，但应记入里程碑（`../PROJECT_REQUIREMENTS.md` 13.3 M0）。

## 4. L4 真实伤害：两个方向都会伤人

### 4.1 假阴性（我们说"没变化"，实际有问题）

| 因素 | 说明 |
|---|---|
| AD 的语言变化出现得**很晚** | 临床前阶段可能完全测不到 |
| 模型性能有限 | ADReSS 上 SOTA 准确率约 80%，且是在**有临床确诊标签的受控录音**上 |
| 家庭环境退化 | 云 ASR + 方言 + 环境噪音，性能会明显下降 |

**后果**：家属因为"App 说正常"而延误就诊。

**产品对策**：全站**不承诺"正常"**，措辞永远保留"继续观察"，不输出"没问题"这类结论。

### 4.2 假阳性（我们说"有变化"，实际没问题）

混杂因素清单：

| 类别 | 具体因素 |
|---|---|
| 生理 | 感冒、鼻塞、疲劳、睡眠不足、牙齿/假牙问题 |
| 设备 | 助听器、麦克风位置、手机型号差异 |
| 环境 | 背景噪音、房间混响 |
| 语言 | 方言口音、ASR 对方言的识别质量 |
| 情绪 | 当天心情、话题内容本身 |

**后果**：家属焦虑、老人被贴标签、家庭关系紧张。

**产品对策**：状态升级必须缓慢（S4 需连续 3 次、S5 需 4 周）；**每条"变化"提示必须并列非疾病解释**，且视觉比重 ≥1/3；事件标注功能（感冒/搬家/住院）就是为了让家属能解释掉这些波动。

## 5. L3 个人信息

### 5.1 双重敏感个人信息

| 数据类型 | 敏感类别 |
|---|---|
| 语音 | **生物识别信息**（含声纹） |
| 认知健康相关记录 | **医疗健康信息** |

两者都属于《个人信息保护法》第 28 条定义的**敏感个人信息**。

**义务**（同法第 28–29、55 条）：

- 单独同意（不能与用户协议合并）
- 告知处理的必要性与影响
- 上线前完成个人信息保护影响评估（PIA）并留档
- 最小必要

### 5.2 第三方个人信息（本项目特有）

**家属录制老人的语音，属于处理第三方（老人）的敏感个人信息。** 这既是法律风险也是伦理风险——子女的关心可能正是父母抗拒的"被监测"。

**产品对策**（见 `../PROJECT_REQUIREMENTS.md` 9.2.2）：

1. 老人知情必须**独立成步**，不藏在长条款里
2. 老人版同意必须**大字 + 可 TTS 朗读**
3. 老人端必须有**随时可见、可撤回**的同意入口
4. **删除权归老人本人**，家属不能单方面删除

> ⚠️ 若老人已丧失民事行为能力、由家属作为监护人，上述第 4 条需按监护关系调整。这是**法律判断**，需法务出意见。

### 5.3 数据出境

- **ASR 与对象存储必须境内**（建议讯飞 / 阿里云 / 腾讯云）
- 禁止境外 ASR API（OpenAI Whisper、Google STT、Azure Speech 等）
- 若必须出境，需先完成安全评估与备案

**这条对论文方向特别相关**：学生项目很容易顺手选境外服务，必须在选型时就定死。

## 6. 文案红线光谱

从绝对安全到绝对红线，五档：

| 档 | 示例 | 判断 |
|---|---|---|
| 0 安全 | 「已保存。你可以把这份记录带给医生看看。」 | 只搬运数据，不做判断 ✓ |
| 1 基本安全 | 「如果你自己也觉得说话不如以前利索，可以找医生聊聊。」 | 判断权交还用户 ✓ |
| **2 灰区（当前设计在这里）** | 「最近 4 周的语速比前 4 周慢，建议就医评估。」 | 与指标绑定的分诊建议，风险可控 △ |
| 3 危险 | 「老人可能处于认知功能下降的早期阶段。」 | 构成疾病判断 ✗ |
| 4 绝对红线 | 「认知障碍风险概率 72%，建议尽快做 MoCA 评估。」 | 诊断结论 + 检查建议 ✗✗ |

**档 4 还藏着一个不易察觉的变体**：把「语速下降 15%」做成结构化报告递给医生。输出对象从用户变成医生，功能性质就从健康提示变成决策支持软件。

**守住档 2 需要两个前提**：必须并列非疾病解释；永不出现数值与概率。
